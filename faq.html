Frequently asked questions.

Basic information about the project and its downloads.

Is MoonClient an official Lunar Client release?

No. MoonClient is an independent project with its own branding. It is not affiliated with Lunar Client or Mojang.

Which Minecraft version does it support?

Check the specific release notes and installation instructions. Compatibility depends on the build you download.

Where does the download button get the JAR?

It downloads a file named pvp.jar from the same folder as this website. Add your own authorized MoonClient build there.

Does this website include the client JAR?

No. The website is a front-end template. The client JAR must be supplied separately by the project maintainer.
