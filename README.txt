MOONCLIENT WEBSITE

Files:
- index.html: homepage
- features.html: features page
- about.html: how the project was made
- download.html: download page
- changelog.html: release notes
- faq.html: FAQ
- style.css / site.js: shared styling and navigation

LOGO:
Put your logo in this folder as logo.png or logo.jpg.
The pages try logo.png first and fall back to logo.jpg.

DOWNLOAD:
Put your own authorized MoonClient JAR in this folder named pvp.jar.
The Download button links to that file. This website ZIP does not include a client JAR.

PREVIEW:
Open index.html in a browser. For a hosted site, upload all files in this folder together.
