Behind the client

How MoonClient was made.

MoonClient started with a simple idea: build a Minecraft client experience with the clean menus, useful customization and smooth presentation that its creator wanted to use.

01

Start with a vision

The project began with a goal for a polished client interface and a recognizable visual identity of its own.

02

Build on the mod

The in-game client is developed around its Minecraft mod project, bringing menus and supported features together.

03

Make it MoonClient

The final direction uses MoonClient branding, custom visuals and its own project identity.

About inspiration: MoonClient is an independent fan project. Its interface takes inspiration from modern Minecraft clients, but it is not an official Lunar Client product and is not affiliated with Lunar Client or Mojang.

A project in progress

Features and compatibility may change between builds. Check the release notes and included instructions before installing.
